# WADDI (6amMart) - 4-DAY UI REDESIGN PLAN

## PROJECT OVERVIEW

Waddi is a comprehensive multi-vendor Flutter application that serves as a marketplace for:
- Food delivery from restaurants
- Grocery shopping from supermarkets
- eCommerce from various stores
- Pharmacy services for medicines
- Parcel delivery services
- Rental services for equipment/vehicles

**Current Architecture**: Clean Architecture with GetX state management, 25+ feature modules

## UI DESIGN SYSTEM

### Color Palette
- **Primary**: Brand colors with accessibility compliance
- **Secondary**: Complementary colors for accents
- **Semantic**: Success (green), Warning (orange), Error (red), Info (blue)
- **Neutral**: Grayscale for text and backgrounds
- **Dark Mode**: Complete dark theme support

### Typography
- **Font Family**: Roboto (as specified in app constants)
- **Scale**: H1 (32px), H2 (28px), H3 (24px), H4 (20px), H5 (18px), H6 (16px)
- **Body**: Regular (14px), Small (12px), Caption (10px)
- **Weights**: Light (300), Regular (400), Medium (500), Bold (700)

### Component Library
- **Buttons**: Primary, secondary, text, icon buttons with states
- **Input Fields**: Text, number, email, password, search with validation
- **Cards**: Product, store, order, notification cards
- **Navigation**: Bottom nav, drawer, breadcrumbs, tabs
- **Feedback**: Alerts, toasts, modals, loading states

### Animation Guidelines
- **Duration**: Fast (150ms), Standard (300ms), Slow (500ms)
- **Easing**: Material Design curves for natural motion
- **Micro-interactions**: Button press, form validation, loading states
- **Page Transitions**: Slide, fade, scale transitions between screens
- **Loading States**: Skeleton screens, shimmer effects, progress indicators
